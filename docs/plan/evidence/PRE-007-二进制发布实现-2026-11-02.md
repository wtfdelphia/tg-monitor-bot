# PRE-007 二进制发布实现记录

日期：2026-11-02

本记录覆盖 `PRE-007-二进制生产发布` 的实现片，不代表已经在生产稳定版本 tag 上发布，也不代表目标机生产安装、数据库迁移或 cleanup timer 已启用。

## 已实现

- 新增独立 `.github/workflows/binary-release.yml`，不修改 `ci.yml`；只接受 `vMAJOR.MINOR.PATCH` tag，并核对 tag 提交属于 `main` 历史。
- 发布前检查 tag 提交的 `static`、`database` check-run；workflow 使用 GitHub OIDC 的 cosign keyless 签名，不保存长期私钥。
- 新增固定摘要的 CentOS 7.9 builder，使用锁定 Rust 工具链和 `--locked` 构建 `tgm`；`josekit` 启用 vendored OpenSSL，避免目标机依赖动态 OpenSSL。
- 新增确定性打包脚本，生成版本目录、`BUILDINFO.json`、Cargo.lock 摘要、包内 `SHA256SUMS`、CycloneDX SBOM、cleanup systemd 工件和离线安装器。
- 新增安装前预检：签名、外层及包内校验、x86-64、glibc、OpenSSL、动态依赖、systemd unit/timer 和命令帮助；预检失败不切换当前版本。
- root 模式安装到 `/opt/tgm/releases/<version>` 并原子更新 `/usr/local/bin/tgm`；非 root 模式只写用户目录；两种模式均不执行迁移、不启动服务、不启用 timer。

## 本地证据

- Shell、Python、YAML 和 diff 静态检查通过。
- 当前环境原生预检通过：动态依赖无缺失、无动态 `libssl`/`libcrypto`、systemd unit/timer 校验通过、`tgm --help` 与 cleanup help 通过。
- CentOS 7.9 builder 镜像 `sha256:e3aa460afdd27309abb4f252691328e8e9952f792072e9ac9f5337521eaca7e2` 已生成二进制；`readelf --version-info` 观察到的最高 glibc 符号为 `GLIBC_2.17`，帮助命令通过。
- 本地发布包演练通过：归档外层 SHA-256、包内 `SHA256SUMS` 和全部包内文件校验均通过。
- 隔离 HOME 的非 root 安装通过；篡改归档后外层校验失败，已有版本 symlink 未切换。
