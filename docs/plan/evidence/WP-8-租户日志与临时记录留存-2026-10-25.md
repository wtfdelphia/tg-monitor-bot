## 一、实现范围

- 追加角色与权限迁移，不改旧迁移、不加业务表或依赖。`tenant_cleanup` 直接登录，
  无超级权限、BYPASSRLS、额外成员关系或业务对象所有权。生产迁移不写口令，本地测试身份单独预置。
- 新命令 `tgm cleanup-tenant --category` 覆盖 login-sessions、notify-dedup、bot-console-updates、
  delivery-logs、audit-logs、system-logs；期限与频率沿用规格，不在本文件另定。
  仅接受专用连接配置，拒绝其他已登记凭据及 `DATABASE_URL`，普通服务和鉴权清理反向拒绝该连接串。
  不初始化 KMS、Telegram、Redis 或对象存储客户端。
- 按主键分页枚举全部状态租户；每批事务设置租户上下文，从数据库取 cutoff，按完整键排序限批。
  删除语句再次检查时间字段，保护并发续期和刷新；投递日志经父任务判租户，不删除父任务。
  审计日志按删除语句快照可见的 plan 判断，不跨批缓存，不明 plan 不回落到 free。
- 同租户同类别使用事务级 advisory lock；重叠批次跳过、不写成功日志，批间释放锁并等待。
  删除与固定当前租户的 `tenant_retention/cleanup.done` 日志同事务提交；context 仅含表名、行数、耗时。
  失败回滚并非零退出，错误不输出底层 SQL、连接串或约束名。SIGTERM 取消未提交批次，已提交批次保留。
- 新增 `C9` 精确权限白名单、双遍破坏与撤销；修正 `C1` 对业务角色策略的检查，定义文档与实现同步。
  提供独立 OS 用户、环境文件与六类 systemd timer 样例，未安装到生产。

租户 GUC 是受信清理进程选择上下文的手段，不是不可伪造的身份凭证。
该角色本来就要轮流处理全部租户，但切换后仍只能删除当前租户的到期行，不能读取 token、正文或日志详情。
审计日志删除语句开始后的套餐升级不追溯恢复已删除记录；不能声称清理与套餐更新全程串行。

本片不覆盖事件、投递任务、规则版本、平台日志、媒体、租户注销、同意文本或举报入口，
不代表整个 WP-8 通过，也不代表周期清理已在生产启用。

## 二、定向验证与修正

清理行为均以 `tenant_cleanup` 真实连接验证，不使用带测试恒真策略的管理池代跑。
管理池只负责种子、观察、测试 DDL 与结果核对。

- 各类别覆盖到期/未到期、free/pro、空批、重跑、超批量和相同业务键的跨租户独立性。
  数据库内部测试实际调用删除 SQL，验证恰好 cutoff 删除、晚一微秒保留。
  六类超批量均验证分批与上限，不仅检查常量。
- 分页测试覆盖 active/suspended/deleted，验证满批等待、锁重叠跳过及停止后重跑。
  三类可刷新的时间字段用真实行锁竞争验证；先观察 `pg_locks` 的等待，再提交续期，不用 sleep 猜时序。
- 权限测试直接执行不带到期 WHERE 的六类 DELETE，证明 RLS 本身保留其他租户、未到期及平台行。
  另验证敏感列、其他表、会话/任务改写、TRUNCATE、角色切换和非法日志写入拒绝。
- 审计日志验证已提交套餐在下一批生效，以及删除已等行锁时提交升级仍按语句快照处理。
  日志写入故障导致删除回滚，停止行锁等待中的 CLI 可及时退出，释放后重跑成功。
- `C9` 定向反证覆盖漏授、多授、MAINTAIN 和列/序列转授权限。
  最后复查发现最初断言没有检查序列 GRANT OPTION，补齐检查及真实反证，未修改既有 `C8` SQL。
- 初次完整门禁中 workspace 测试为 396 passed / 0 failed / 21 ignored，
  但双遍删除 `delivery_logs` 业务策略后，旧 `C1` 仍为绿，因此整轮失败，未计作验收通过。
  原因是新增清理策略使表上策略总数仍非零；修正为检查对业务角色生效的策略，
  保留原破坏方式，并新增“清理策略仍在但业务策略缺失”的回归。最终必须从头重跑完整门禁。
- 仓库外 SQL/文档一致性探针首次误将 SQL 后的 `C3` 说明注释纳入比较而报错；
  缩小到 `C9` SQL 段后检查通过。保留失败日志，没有修改 SQL 或文档来迎合错误探针。

定向日志为 `db-focused-final.log`、`focused-expanded.log`、`c9-sequence-verified.log`；
首次完整失败日志为 `gates.log`，辅助检查失败与修正分别为 `final-checks.log`、`final-checks-verified.log`。
