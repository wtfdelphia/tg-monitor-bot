## 一、问题与实现

规则版本列表与单版本快照 API 已实现，但规则编辑页没有对应入口。
本轮接入按需加载的只读面板，显示版本、创建时间与当前编辑版本标记，支持刷新和查看快照。
新建规则在保存前只显示提示，不查询不存在的历史。

版本加载与快照选择共用面板内的忙状态，避免重复请求或旧响应覆盖新选择。
请求失败保留已有列表与快照，恢复按钮并提示；不会覆盖未保存的表单，也不发写请求。
版本列表中的文本经 HTML 转义，快照与错误提示使用 `textContent`。
快照仅投影规则、条件和替换中的白名单业务字段，内部租户字段不进入展示或表单参数。
这是页面呈现边界，不是修改 API 响应或服务端隔离规则。

复用现有 Node 标准库执行入口与业务页面测试环境，不新增依赖。
没有改认证 handler、权限规则、数据库查询、迁移、RLS、GRANT、审计断言、CI 或门禁脚本。
面板沿用现有规则编辑页角色限制，不新增独立路由或回滚操作。
