- `CI`
- `Native binary candidate`
- `Docker build validation`

仓库 `dev` 树中存在 `.github/workflows/docker-publish.yml` 和
`.github/workflows/binary-release.yml`，但它们尚未进入 GitHub 默认分支，因此 GitHub
尚未注册对应 workflow，也没有可引用的实际发布 job 运行记录。不能把本地文件存在记为
GHCR 发布或正式二进制发布已验收。

这不是本次提交直接修改 `main` 的授权。后续需要维护人决定是否将两条发布 workflow 通过
单独的、明确以 `main` 为目标的 PR 引入默认分支；在此之前不触发正式发布，也不推送 GHCR。
