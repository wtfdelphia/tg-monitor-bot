## 三、敏感信息边界

- 不要在聊天或仓库提交密码、令牌、连接串、`api_hash`、私钥、备份密钥、生产环境文件或完整配置。
- 日志与证据仅提供脱敏摘要和受控存储位置；环境文件只回报 owner、权限位和校验结果，不回传文件内容。
- 生产只读权限、探针租户和运行授权分开记录；提供验收输入不等于批准启用 timer 或删除真实数据。
- 如输入改变表结构、权限、RLS、审计、清理语义、公开 API 或部署配置，先按仓库升级纪律单独提案。
