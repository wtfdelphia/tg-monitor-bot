# WP-8：租户物理清理运行入口与权限缺口验收证据

任务 id：`WP-8-tenant-purge-runtime`。

本记录覆盖运行入口、独立配置、systemd 工件，以及批准后的 `0062` 最小列权限补充；不代表
真实生产租户删除已经执行，也不代表 WP-8 整体出口已经通过。

实施分支：`codex/WP-8-tenant-purge-runtime`，基于 `cloud/dev` 的 PR #64 合并提交。

## 一、实现范围

- 新增 `tgm purge-deleted-tenants [--tenant-id] [--max-tenants]`，按固定七类顺序运行短批次，
  只有 `tenant_purge_finalize()` 返回 `deleted` 才计为完成。
- 新增独立 `TGM_DB_URL_TENANT_PURGE` 配置边界，拒绝 PgBouncer 端口 `56432`、`56433`，
  启动时核对登录角色、事务隔离级别和直连后端 PID。
- 新增 `tgm-tenant-purge.service`、`tgm-tenant-purge.timer` 和示例环境文件，服务使用
  独立系统用户与最小 systemd 沙箱设置。
- 批处理权限缺口经批准后新增 `migrations/0062_tenant_purge_source_ref.sql` 及测试迁移，
  只授予 `tenant_events.source_ref` 与 `rules.target_ref` 的 SELECT 列权限；未修改
  `0056`–`0061`。
- C17 和专项权限测试同步这两个引用反查列，拒绝其他列权限漂移。
