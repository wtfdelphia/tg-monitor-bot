## 首发阶段需要了解的服务边界

1. **单实例单点**：服务采用单实例形态；进程停止时服务会中断，目前没有自动接管。
2. **没有值班保障**：当前没有可保证在特定时限内响应的值班安排。
3. **没有 SLO 或 SLA**：目前没有定义服务级目标，也没有服务级协议。
4. **RPO / RTO 尚未定义**：目前没有可对外承诺的数据恢复点目标或恢复时间目标。
5. **容量尚未实测**：`2 vCPU / 4 GB` 是估算值，尚无实测依据；容量超限表现为 OOM，而非降级。
