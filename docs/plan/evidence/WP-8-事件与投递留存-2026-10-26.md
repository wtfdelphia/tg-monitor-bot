## 一、实现结果

- 新增 `migrations/0031_event_retention.sql`，并在 `migrations-test/0032_event_retention.sql` 以符号链接复用生产迁移。
- `delivery_tasks.(tenant_id, tenant_event_id)` 改为只将 `tenant_event_id` 置空的 `ON DELETE SET NULL`；`tenant_id` 保持非空。
- `delivery_logs.task_id` 改为 `ON DELETE RESTRICT`，防止任务删除提前抹掉投递记录。
- 事件留存新增 `tenant-events` 和 `delivery-tasks` 类别；任务清理仅处理已脱钩的 `DONE`、`DEAD`、`CANCELLED` 任务，并按日志存在、终态和期限重新判断。

- 入队、claim、stale recovery、retry、complete、failure、defer 均接入事件生命周期共享 advisory lock；脱钩任务不会再进入投递状态机。
- `tgm cleanup-tenant`、systemd timer 样例、数据模型、生命周期、部署和 CI 门禁文档同步更新。
- 测试夹具补齐真实 `tenant_events` 与 `source_subscriptions` 关系，并按 `delivery_logs -> delivery_tasks ON DELETE RESTRICT` 的顺序清理。
