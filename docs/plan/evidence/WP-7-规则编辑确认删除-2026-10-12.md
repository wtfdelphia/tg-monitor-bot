## 一、问题与实现

单规则 DELETE API 已存在，编辑页原先没有删除入口。本轮为已保存规则增加确认删除，
复用该 API 和 `runWrite`，不新增端点。删除按钮是普通按钮，不触发表单提交，
只在所有者或管理员编辑已保存规则时显示。

确认提示说明条件、替换与版本历史随规则删除，操作不能撤销；已入队任务不会因此取消。
删除与保存共用规则表单的锁，禁用同一组控件，重复删除或保存不能启动第二次写入。
取消确认不发请求。删除成功后返回列表，未得到成功响应则保留表单、恢复原禁用状态，
用纯文本提示先刷新列表核对再决定重试，不把 404 当作本次删除成功。

不增加依赖，不改 handler、Repo、表结构、迁移、RLS、GRANT、审计、CI 或门禁。
没有提供批量删除，也未接入其他上线阶段功能。
