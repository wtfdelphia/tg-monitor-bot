## 一、复核范围

本基线 `migrations/` 含 58 个 SQL 文件。文件主题以迁移注释和实际 SQL 目标交叉核对；对象
范围按文件内 DDL、策略、函数及授权语句记录。`tgm_owner` 表示迁移/schema 所有者，不代表
应用运行身份；业务访问仍按 `eng/02` 权限矩阵由 `app_user`、`auth_lookup`、运维只读角色及
专用清理角色分别承担。清理角色不因此获得通用业务访问权。
