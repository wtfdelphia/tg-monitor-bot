1. 管理池先断言业务对象为空；浏览器用真实 API 再断言列表为空，不看到其他租户种子。
2. 经页面接入测试 Bot，真实 handler 调用本地 `getMe` 桩并保存凭据密文，表单清空。

4. 页面创建关键词与规则，规则明确选用本轮创建的目标和关键词；刷新编辑页后引用不变。
5. 管理池核对各类对象均只有本轮页面创建的记录，规则、关键词、目标和身份同租户关联，凭据为 EnvKek 密文而非测试 Token 明文。
