## 一、范围与安全边界

- 在从 `cloud/dev` 创建的独立 worktree 中执行。
- 使用 `SQLX_OFFLINE=true cargo build --release --locked -p tgm` 构建，不连接数据库。
- 只运行二进制的帮助命令，不运行迁移、审计、清理或任何需要外部服务的子命令。
- 使用临时环境文件和临时 unit 副本验证 systemd 解析，不安装或启用系统 unit。
- 不连接 PostgreSQL、Redis、对象存储、Telegram、KMS 或任何生产服务。
- 不读取、生成或写入真实凭据，不创建探针租户，不执行租户删除。
