## 一、实现与边界

- 追加 `0034_unmatched_event_retention.sql`，测试迁移通过符号链接复用；旧迁移未改。
  `tenant_cleanup` 只增加投影处理元数据和原始事件必要元数据列的读取，不增加正文、凭据、payload 或共享事件写权限。
  投影 SELECT 可见与 DELETE 到期条件分开，短期 DELETE 仍限定当前租户、处理完成、未命中、
  父事件扇出及年龄、无任何状态任务引用。既有套餐删除路径及任务脱钩语义不变。
- 新增 `cleanup-tenant --category unmatched-events`，复用租户枚举、批量、事务日志、取消和生命周期锁。
  期限从原始事件创建时间起算，恰好 cutoff 保留；不从投影或处理时间重算。
  命令输出 `retained` 统计到龄未命中投影，存在受保护记录时明确提示，不计作已回收。
  重叠未执行或中断在该类别中非零退出。
- 共用扇出入口持租户生命周期共享锁，再持身份共享锁。完成扇出的事件可返回已有投影，
  但不重建已清理投影；未完成扇出的崩溃重跑仍可补齐缺失投影。
  共用入队入口在事件行锁后复查处理终态；旧计划不新增任务，已有幂等任务返回原记录。
  后台列表项被并发回收不会使循环退出，直接查不存在的事件仍是 `NotFound`，其他 SQL/规则故障不吞掉。
- 共享回收继续保护全部投影、媒体组和有效下载，角色与引用外键未放宽。
  `tgm-shared-cleanup.service` 用显式 `Requires`/`After` 先完成未命中投影清理，再使用共享清理身份运行。
  两个进程不共享数据库凭据；前置失败不启动共享 service。
- 新增 ADR-0036 并同步架构、生命周期、权限、索引、运维与测试策略。
  年龄门槛不是精确时刻硬删除承诺，未处理、引用、有效下载和故障会延后回收。

## 二、定向检查与反证

db 用例覆盖固定 cutoff、原始事件与投影时间不同、多租户 free/pro、处理终态、全部任务状态、
未扇出、旧计划入队及扇出重放、媒体组间接引用、下载保护和 READ COMMITTED 拒绝条件。
两个真实连接观察锁等待，验证写入与清理的两个提交方向，以及投影清理与共享回收同时运行。
权限断言使用真实 `tenant_cleanup`/`app_user`/`shared_cleanup` 连接，不用测试控制角色验证隔离。

行为反证放宽短期 DELETE 策略后，原本不能删除的未处理投影变成可删，事务回滚后数据仍在。
`C9` 定向反证覆盖正文超授、必需元数据漏授及处理列转授；撤销后审计恢复。
双遍的 `C9` 反证改为超授原始正文，不改变其他断言口径。
另实际移除扇出的生命周期共享锁、处理终态判断和扇出终态判断，各自定向用例均失败；
恢复全部保护后重新跑最终完整门禁。扇出终态 SQL 反证采用在线宏编译并直接运行测试二进制，
测试控制连接与编译 schema 连接分开，避免把 schema 库权限错误冒充行为反证。

app 用例覆盖批量上限、批间等待、取消时行锁等待中的删除与日志同时回滚，重跑可完成；
CLI 覆盖独立凭据、受保护记录提示、重叠非零退出。pipeline 验证已回收事件不重建，后续新事件仍可处理。

首轮测试曾使用不存在的 `IdentityId::new`，已改从数据库解码；媒体组计数误用无该表权限的
测试控制连接，已改用已有受限业务连接；日志合计以 `NUMERIC` 返回，已显式转换为 BIGINT。
SQLx 初次检查撞上编写中的依赖接口，重跑在线 prepare 成功。上述失败均不计为通过。

## 三、隔离空库与调度

使用任务专属 `--network none`、tmpfs PostgreSQL 容器和 Unix socket，
由 `tgm migrate` 从空库创建角色并执行迁移、运行审计。种子包含可删未命中投影、未处理、近期和未扇出事件。
先单跑共享命令不删有投影事件，再由临时 user timer 触发有显式依赖的两个清理 service。
两阶段分别只配置自身连接串，日志顺序与删除数吻合，受保护事件仍在。

将隔离容器中的租户清理角色临时改为 NOLOGIN 后，前置 service 失败，
共享日志不增加；恢复登录并完成处理/扇出后重跑，剩余到龄事件可回收，近期事件保留。
首轮验收遗漏共享清理的最终零删除日志，导致期望日志序列错误；修正后整条验收通过。
临时服务、timer、容器和 socket 已清除，现有 Compose 栈与具名卷未动。

临时 user service 仅证明同一用户会话下的进程凭据分离和依赖顺序；
不代表生产专用系统用户、Secret 文件权限、真实小时周期或告警已验收。
生产样例另经 `systemd-analyze verify` 校验：只将 `/usr/local/bin/tgm` 替换为本地二进制，退出零。
宿主 systemd 同时报出无关的 netplan 单位读取和 snapd `RestartMode` 提示，未修改这些系统配置。
