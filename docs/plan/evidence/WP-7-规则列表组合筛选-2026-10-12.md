## 一、问题与实现

规则列表 API 已支持启停、目标引用与来源引用筛选，控制台原先只传分页参数。
本轮接入现有查询参数，不新增 API 或数据库查询。

页面增加组合筛选与清除入口，所有查看角色都可使用。引用 ID 保持字符串，
用 `URLSearchParams` 编码，不经 `Number` 转换，也不拼接租户参数。
成功筛选从第一页重置列表与选择；失败保留已加载规则、选择和表单输入。
加载更多沿用最近一次成功的筛选条件，失败尝试不覆盖这份状态。

列表加载期间锁住筛选、分页和批量写入控件，批量写入期间也禁用筛选。
事件入口同时检查状态，避免重复事件或跨控件事件启动并发操作。
请求结束恢复原禁用状态，不把原先禁用的控件误启用。
新增列表加载锁仅约束这张页面，不替代服务端权限或事务。

不新增依赖，不修改 handler、Repo、迁移、RLS、GRANT、审计、CI 或门禁。
没有提前接入首发仍留位的规则试跑或其他上线阶段功能。
