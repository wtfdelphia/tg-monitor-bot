## 实施内容

- 为 `control-plane`、`bot-gateway`、`mtproto-worker`、`fanout`、`rule`、`delivery` 提供独立实例化的 systemd system/user 模板和角色环境示例。system 模式使用专属非 root 账号；user 模式明确不提供同 UID 进程间的凭据隔离。
- `tgm serve` 增加显式 `--env-file` 与 `--check-config` 路径，复用角色配置白名单并拒绝未知、多余、权限过宽或路径不安全的配置；检查错误不回显配置值。
- 原生安装器增加独立的 `--app-services` 选择，保留 root/user 安装边界；不覆盖现有 unit 或实际配置，不启动服务、不启用 unit、不执行数据库迁移。升级和回滚会检查已安装应用模板与二进制兼容性。
- 原生发布预检、归档打包和二进制发布 workflow 纳入应用 unit 与六个角色的离线配置入口检查。
- 调整 `rule` 连续失败测试为相对既有 `NRestarts` 基线至少增加三次，避免依赖 manager 计数器必须恰好等于固定值；unit 仍将 `StartLimitBurst=3` 作为重启限制。
