## 二、建议实施范围

只扩展现有身份页，不新增顶层页面、依赖或前端框架。

1. Bot 接入表单：仅所有者/管理员可见，复用 `POST /api/v1/identities/bot`、
   同源 Cookie、CSRF 与既有提交锁。输入框使用密码类型，不预填、不回显 Token。
   发出请求前清空输入，成功刷新身份列表；失败只展示固定或白名单错误提示，不把错误响应原文渲染为 HTML。
2. MTProto 接入：展示与“控制台登录”的区别，明确代持凭据风险与当前授权版本。
   用户主动勾选后才发送 `consent_text_version`；不默认勾选、不在后台代替用户同意。
   复用 `POST /api/v1/identities/login/qr` 与状态轮询，只发送既有请求字段。
3. QR/2FA：按既有接口展示当前二维码与过期状态，不插入未经验证的 SVG HTML。
   用独立图像元素承载服务端 QR，二维码不外传、不写下载文件或持久缓存。
   轮询按 spec/07 §3.3 的前端间隔串行执行，超时、终态、离页或重试时停止旧循环，
   旧请求晚到不得覆盖新一轮状态。2FA 仅在对应状态出现，复用既有密码端点。
4. 重新授权：仅对现有 MTProto 身份展示入口，复用 `identity_id` 与服务端账号一致性校验。
   不允许浏览器指定租户、不新增绕过账号匹配的参数、不将“状态复位”伪装成重新授权。
5. 凭据清理：`api_hash`、Token、密码仅保留于当前提交所需的短期内存；
   请求发出前清空输入，不在失败后恢复，不进 URL、日志、DOM 数据属性、存储、剪贴板或截图证据。
   终态、离页和重试清理图像及旧登录材料；现有服务端登录过期清理机制保持不变，不假设存在取消端点。

当前 API 的授权版本是占位 `custody-v0`。本片会明确说明 session 的权限范围及平台代持风险，
但不自行把占位版本升级成正式法律文本，也不改版本常量或落库语义。
如果维护人要求先定正式文本，则先拆出授权文本任务，本片 MTProto 提交入口保持关闭；
不得为了交付页面而静默绕过同意记录。

## 三、复用与不在范围

复用 `console.rs` 的页面、角色识别、CSRF、提交锁和列表刷新，
复用已批准的 Bot/QR/2FA API、`QrLoginStore`、wrap-only 写入及租户/用户绑定。
不新增表、迁移、角色、GRANT、KMS 权限、解密能力、API 参数或 QR 驱动抽象。

以下内容不在本片批准范围：

- 控制台登录页的二维码图像交付，另作小片；不把它和 MTProto 的 bearer 二维码混为一条链路。
- 目标频道自检、探测队列/worker、权限结果回写及相应迁移/安全面设计。
- OIDC 真联调、Telegram 真机、生产 KMS、法务定案或 WP-8 留存/删除。
- 宣布整个 WP-7 通过或合并。

## 四、测试与验收

按 `docs/design/eng/03-测试策略.md` 的现有分层，不另建测试框架。

- Node 执行真实页面脚本：角色隐藏、显式同意、请求字段及 CSRF、重复提交互斥、
  失败清空凭据、状态轮换、错误密码重试、终态停止、离页停止与旧响应拒绝。
- 浏览器夹具复用现有 SQLx 临时库和受限角色；Bot Token 使用虚构测试材料及本地 Bot API 桩，
  由真实 HTTP handler 校验并加密落库。图片渲染、输入清空、键盘焦点、窄屏、只读角色和请求租户参数检查显式运行。
- MTProto 正向状态轮换先用明确标记的本地 HTTP 桩验证页面，不把桩写成真实 QR 驱动或 Telegram 验收。
  真实 handler 的权限、pro 门槛、同意版本、CSRF、跨租户/跨用户拒绝沿用既有集成测试。
- 页面检查加入反证：提前清空凭据被移除、错误角色可见、重复请求、旧响应覆盖新状态、
  未勾选同意仍提交、终态继续轮询时，对应检查必须失败。反证仅在测试内存中执行，不改生产边界。
- 显式运行浏览器用例；默认 `ignored` 不算通过。再运行完整 `scripts/ai-driver/ai-gates.sh`，
  每 60 秒核对进度；最终仍以 PR CI 裁决。
- 归档不含凭据的日志，检查磁盘与任务专属 target，及时清理构建缓存及可确认归属的临时 Docker 资源，
  不删除现有 Compose 栈、具名卷或测试证据。

预期改动限于 `crates/app/src/console.rs`、相关 Node 页面检查、
`crates/app/tests/control.rs`、`crates/app/tests/console_browser.rs` 与浏览器脚本，以及本片证据。
