# ADR-0036：已处理未命中投影采用短期留存

状态：2026-10-26 维护人批准 `WP-8-unmatched-event-retention` 提案后实施。

## 背景

ADR-0009 把原始事件定位为过路数据，ADR-0015 不允许把正文积累成内容库。
但按套餐期限保留全部租户投影，会阻止未命中原始事件按短 TTL 回收；
直接级联删除投影，又会丢失尚未处理的工作或其他租户的投递引用。

## 决定

已完成规则处理、未命中且没有任何状态投递任务引用的投影，在其原始事件完成扇出并达到
`spec/04` §一的未命中期限后，可以提前删除。不从投影创建时间或处理时间重新起算。
其余投影仍沿用套餐留存和既有在途任务保护，不缩短投递记录、日志与冻结 payload 的期限。

每个租户只清理自己的未命中投影，其他租户的未处理、命中或任务引用不受影响。
原始事件继续由独立共享清理身份核对全部引用、媒体组和下载状态后回收。
`matched_any` 保持累积语义，不因删除某个租户投影而重置。

年龄门槛不是精确时刻硬删除承诺。未完成处理、存量引用、有效下载或失败重跑都可能延后回收，
必须报告滞留或失败，不能通过提前删除工作来宣称符合 TTL。
小时调度先执行租户未命中投影清理，再用独立身份执行共享事件清理。

## 影响

细化 ADR-0009/ADR-0015 的留存语义，不取代两层模型或转发工具定位；
取代投影无论处理结果均保留至套餐期限的要求。已回收的投影不再支持历史重处理，
完成扇出的事件不得重新生成投影，过时规则计划不得为已完成处理的事件新增任务。
未完成扇出的崩溃恢复仍可补齐缺失投影。

清理复用 `tenant_cleanup`，增加必要处理元数据读取与受限 DELETE 策略，
不授正文、凭据、冻结 payload 或原始事件写权限。并发保护覆盖本仓共用入口，
不声称能限制绕过入口的任意直接 SQL。期限、权限和调度以规格及运维文档为准。
