# ADR-0035：目标自检经持久待办异步返回

状态：2026-10-23 维护人批准 `WP-7-target-probe` 提案后实施。

## 背景

ADR-0019 要求配置目标时检查发送 Bot 的权限，并当场返回。控制面只有 KMS Encrypt，不能为了同步返回取得解密权；组件间也不能新增 RPC。

## 决定

创建目标与登记自检在同一 PostgreSQL 事务完成，返回 201。显式自检返回 202，在途重复请求复用当前代次。delivery 独立执行只读 Bot API 检查，页面读取持久结果；没有 worker 或查询失败均不显示通过。

复用目标行保存待办、代次、认领租约和结果；发送身份保存自检保留/冷却期限，使同一身份的不同目标及进程重启不能绕过等待。路由、凭据或身份有效性变化使结果失效，迟到响应必须通过代次、租约和凭据版本比较才能写回。

只读检查给出目标基础文字发言权限、Bot 角色及目标自身内容保护。移除没有来源消息上下文的 `can_forward`；不发送测试消息，不把目标保护误作来源保护，也不替换投递动作。

## 影响

取代 ADR-0019 中“结果当场返回”的同步要求；配置时必须自检的首发范围不变。控制面不读取凭据、不新增 Decrypt，组件仍只经 PG/Redis 交接。页面等待结束不取消后台待办；真实 Telegram 权限与实际发送仍须独立验收。

判据与批准范围：`docs/plan/proposals/WP-7-target-probe.md`；接口定义见 `spec/07` §3.8。
